# Процедурная реализация алгоритмов виртуального тура

Данный проект содержит процедурную реализацию двух алгоритмов для веб-приложения, предназначенного для создания виртуальных экскурсий по музеям.

## Язык и версия
*   **Язык:** Python
*   **Версия:** Python 3.13.15

## Зависимости
Внешние библиотеки не используются. Для работы достаточно стандартной библиотеки Python. Файл `requirements.txt` не требуется.

## Инструкция по запуску

1.  Убедитесь, что у вас установлен Python. Проверить версию можно командой:
    ```bash
    python --version
    ```
2. Перейдите в папку src:
   ```bash
   cd src
   ```
3. Запустите первый алгоритм (проверка связей точек перехода):
    ```bash
    python algo_1.py
    ```
4. Запустите второй алгоритм (проверка связности графа тура):
    ```bash
    python algo_2.py
    ```

## Пример входных данных и ожидаемого вывода
## Для алгоритма 1 (algo_1.py)
**Входные данные (заложены в коде):**
* Список залов: 2 зала (ID: 1, 2).
* Список точек перехода: 3 точки. Две корректные (ведут в существующие залы), одна некорректная (ведет в несуществующий зал 99).

**Ожидаемый вывод:**

```bash
Запуск алгоритма проверки связей точек перехода...
Найдено ошибок: 1
- Ошибка: Точка 12 ведет в несуществующий зал 99
```

## Для алгоритма 2 (algo_2.py)
**Входные данные (прописаны в коде):**
* Список залов: 3 зала (ID: 1, 2, 3).
* Тест 1: Связный граф (все залы достижимы друг из друга).
* Тест 2: Несвязный граф (зал 3 является тупиком, из него нет переходов).

**Ожидаемый вывод:**

```bash
Запуск алгоритма проверки связности графа тура...

Тест 1 (Связный граф):
Результат: Связный

Тест 2 (Несвязный граф):
Результат: Несвязный
```
